What's New

Foldwise 1.1.1

  • macOS 27 support: Create with AI uses the local model’s reasoning capabilities when available to better interpret requests. AI processing takes place on your Mac without sending your files to the cloud.
  • More precise rules: Improved handling of multiple conditions, exclusions, and action sequences. Foldwise checks the requested file size thresholds and better distinguishes file criteria from execution times.
  • Clarification for ambiguous requests: Requests such as “trash old PDFs” need a more precise threshold. The draft remains editable so you can review it before saving.
  • Local visual analysis: On macOS 27, when the model supports images, folder suggestions can consider a small sample of local image previews. Visual observations inform the analysis without automatically becoming rules based on image content.
  • Create with AI (Beta): The feature remains in beta and may make mistakes. Always review the draft before enabling the rule. The compatible local engine remains available when the model is unavailable.
Previous Update

Foldwise 1.1.0

  • Create with AI (Beta): You can now create rules using natural language. Just describe what you want to do, and Foldwise will try to generate the rule for you automatically.
  • Beta notice: The AI rule creation feature is still in development and may occasionally make mistakes, especially with complex or ambiguous requests. We recommend reviewing the generated rule before enabling it.
  • Log button in the menu bar: Added a new button to quickly show or hide the log section.
  • Localization: Improved English and French translations.
  • General improvements: Various refinements across stability, usability, and interface polish.
